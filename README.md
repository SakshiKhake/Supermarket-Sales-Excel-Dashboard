# Supermarket-Sales-Excel-Dashboard

An interactive Excel dashboard analyzing 1,000 supermarket transactions across 3 branches (Yangon, Naypyitaw, Mandalay), built using PivotTables, PivotCharts, SUMIFS/AVERAGEIFS formulas, and slicers.

## Dashboard Preview
[Dashboard Preview](Dashboard_preview.png)

Objective:
Analyze supermarket transaction data across 3 branches to identify sales trends, top-performing product lines, and customer behavior patterns.

Dataset:
1,000 transactions from 3 branches (Giza,Alex,Cairo), Jan-Mar 2019. Source: Kaggle Supermarket Sales dataset.

Tools & Skills Used:
Excel Tables, PivotTables, PivotCharts, SUMIFS/AVERAGEIFS, Slicers, Dashboard Design

Key Insights:
Giza branch generates the highest total sales among the three branches.
Cash is the most-used payment method (35%), closely followed by Credit Card(34%) and Ewallet (31%).
Food & beverages and Sports & travel are the top-performing product lines by sales.
Sales dipped sharply in February before recovering in March.
